# Thunderstore Compatibility Status — Saga Unbound 1.0.0

**Status: HOLD for identical 1.0.0 publication on Thunderstore.**

Saga Unbound 1.0.0 is built from the versions actually tested in the supplied Gale profile. That profile contains dependencies sourced from Hexium because those tested versions were not all available through Thunderstore at release-preparation time.

The supported 1.0 installation path is therefore **Hexium + Gale**. Do not downgrade individual dependencies merely to force the pack onto Thunderstore without a new compatibility test.
