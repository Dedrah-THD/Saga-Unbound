# Installation Guide

## Recommended: Gale Mod Manager

Saga Unbound 1.0 was tested with a dependency set spanning **Thunderstore and Hexium**. Use Gale for the supported installation path.

1. Install Gale from its official GitHub or Thunderstore distribution.
2. Select **Valheim**.
3. Ensure both Thunderstore and Hexium sources are enabled in Gale's Valheim settings.
4. Install **Saga Unbound** from its Hexium listing once published.
5. Allow Gale to install all declared dependencies.
6. Launch Valheim with Gale's **Launch modded** button.
7. For the intended experience, create a fresh character and fresh world.

### Why not r2modman / Thunderstore Mod Manager for 1.0?

The tested Saga Unbound 1.0 profile contains dependency versions that are currently sourced from Hexium. Gale supports both repositories; Thunderstore-only managers cannot reproduce that exact profile while those versions remain unavailable on Thunderstore.

## Existing Players / Servers

Back up worlds and characters before changing modpack versions. Do not use an automatic "update everything" workflow on an established server without first reviewing Saga Unbound release notes.

## Troubleshooting

When asking for help, provide the Saga Unbound version, game version, client/solo/dedicated-server context, the relevant BepInEx log, and whether any dependency versions or Saga Unbound configs were changed.
