# Saga Unbound Changelog

## 1.0.1 — Portal Progression Fix

### Fixed

- Corrected portal-tier progression for Black Metal.
- Black Metal could previously be transported through a portal tier one stage earlier than intended.
- Updated the Advanced Portals configuration so Black Metal now respects Saga Unbound's intended progression tier.

No dependency versions were changed in this release.

## 1.0.0 — Initial Public Release

- Initial public release of **Saga Unbound — A THD Valheim RPG Experience**.
- Curated RPG progression across classes, magic, equipment, enemies, dungeons, exploration, seasons, farming, settlement systems and quality-of-life mechanics.
- Public balance profile established for small-group multiplayer while remaining solo-playable.
- Exploration-focused regeneration: slower mine/location/dungeon renewal encourages outward travel instead of repeated local farming.
- Settlement convenience tuned separately from world-resource progression.
- Epic Loot Adventure Mode bounties gated to current-biome boss progression.
- MagicRevamp portal spell configured to respect restricted items and weight checks; summon cap tuned to 4.
- Dungeon size ranges tuned for greater variability.
- PetPantry added with its generated 15 m/default behavior.
- Qmds FishTrap 1.1.4 included using its built-in behavior; no separate Saga Unbound FishTrap config is distributed.
- Gale recommended because the tested dependency set spans Thunderstore and Hexium.
